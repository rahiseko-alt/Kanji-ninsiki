# 記録を持たず、練習は1回の中で完結させる

ログインは付けず（ADR-0002）、さらに練習の記録にも頼らないと決めた。端末に残すのは表示言語と出題範囲の選択だけで、出す字の選び方・難しさの調整・間違えた字の出し直しは、すべて1回の練習（約8分）の中で完結させる。研究では、日をまたいで間を空けて学び直す方法（Rawson & Dunlosky 2011 など）や、字ごとに出題の間隔を合わせる方法（Lindsey ら 2014）が最も効果的だが、端末の記録は消える・混ざる・引き継げないことがあり、仕組みを単純に保つことを優先した（利用者の決定）。根拠の一覧は `docs/research/redesign-evidence.md`。

## Considered Options

- 字ごとの出来を端末に保存し、日をまたいで復習させる（研究上は最良。記録が失われると崩れるため不採用）
- 記録を持たない（採用）

## Consequences

- 「別の日に学び直す」効果は得られない。1回の中の、間を空けた繰り返し・似た字の並置・正答率に合わせた難しさの調整で補う。
- 「どれだけ伸びたか」をアプリ内で測って示すことはできない。
