## 2026-09-27 表紙に開発元の朱の印を置いた

**決めたこと**

- 利用者の指定で、表紙の題字「認字」の右に朱の印「開発元 小齊平 恒平」を置いた（PR rahiseko-alt/Kanji-ninsiki#48 で main に取り込み済み）
- 印は利用者の見本の意匠（角の丸い二重枠、「開発元」は小さく）を、題字の字の高さにそろえた正方形にした。字配りは印の割付の定石（印面を均等に埋める、奇数の名は伸ばしてそろえる、右から読む）に従う。題字と印はひと組にして中央に置く
- 同梱フォントに「齊」が無いため、印は画像で同梱する。作り直すときは scripts/make-seal.py を原本のフォントで実行する

**次にやること**

- 公開後、アプリの表紙で印の見え方を確認してもらう

**未解決の問題**

- 題字が石組みの図や START の中心線から少し左に寄っている。気になるなら題字だけ中央に戻す案がある【曖昧】

## 2026-09-27 練習中の背景を白い和紙にした

- 暗い表示（ダークモード）でも和紙は明るいままで、カードの色と合わない可能性がある。未確認【曖昧】
