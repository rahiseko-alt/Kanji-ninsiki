## 2026-09-25 画面の流れを「表紙→アプリ説明→ホーム→モード選択→練習」にした

**決めたこと**

- 利用者の指示で、開くたびに表紙→アプリ説明（文章が下から上へ流れ、段落ごとに利用者提供の挿絵を添える）→ホーム（始める位置）→モード選択→練習、の順にした
- アプリ説明は、利用者の2つの文章（覚えるアプリではない／慣れが要る・デーヴァナーガリーの例・未末 日目 土士）を利用者の指示で統合した。日本語版はひらがなだけに書き換えた（利用者が選択）。デーヴァナーガリーの例はどの言語でも同じ英語・ベトナム語・ネパール語は Claude の訳【曖昧】ベトナム語・ネパール語は母語話者の確認なし
- 表紙は利用者のデザイン（石組みの図、題字「認字」、NINJI、START）どおり。題字と START はどの言語でも同じ。アプリ名は利用者の指定で全言語「認字」（ブラウザのタブ・ホーム画面に追加したときの名前は「認字 NINJI」）
- アイコンは利用者のデザイン（石組みに「認」）。角丸の外側を紙の色で埋めて正方形にし、各サイズを作った
- 全画面の見た目を表紙に合わせた（紙の白・墨の四角・角なし・字間を空けた明朝）。選んでいるもの（始める位置・モード・段階・盤面の字・下のタブ）は、利用者の指示ですべて墨で塗って示す
- 新しい版を公開したら、アプリを開いたときや戻ってきたときに新しい版へ自動で切り替わるようにした（古い版が端末に残り続けたため）
- アプリ説明は流す演出をやめ、文章と挿絵をまとめた1枚のページを利用者がスクロールして読む形にした（流す方式は利用者の端末で2度とも途中で消えたため、利用者の指示）。右下に常に出る「とばす」（スクロールに追従）でいつでも、ページ最後の「つぎ」で読み終えてからホームへ進める（利用者の指示）
- ホームは利用者の指示で、題字・石組み・始める位置（画面では「レベル1〜3」、補助説明なし）・「はじめる」だけにした（「どこから はじめる？」と「よめなくて だいじょうぶ」は削除）
- 表示言語はどの画面でも右上から切り替えられる。練習の画面上部の段階切り替えは、モード選択の画面に置き換えた
- テスト96件・型の確認が通り、全画面を幅390pxで目視確認した

**次にやること**

- 公開後、アプリを開き直して、説明のページ・挿絵・アイコンを確認してもらう（rahiseko-alt/Kanji-ninsiki#32・#34・#35 で main に取り込み済み。#35 以降は新しい版が自動で切り替わるが、今回だけはアプリを削除してホーム画面に追加し直すのが確実。アイコンはホーム画面に追加し直さないと替わらないことがある）

**未解決の問題**

- ベトナム語・ネパール語の説明文は母語話者の確認が要る【曖昧】
- 明朝体は線の細い部分が小さい画面で見えにくい可能性がある。試用で確かめる【曖昧】
