## 2026-09-25 画面の流れを「表紙→アプリ説明→ホーム→モード選択→練習」にした

**決めたこと**

- 利用者の指示で、開くたびに表紙→アプリ説明（文章が下から上へ流れ、段落ごとに利用者提供の挿絵を添える）→ホーム（始める位置）→モード選択→練習、の順にした
- アプリ説明は、利用者の2つの文章（覚えるアプリではない／慣れが要る・デーヴァナーガリーの例・未末 日目 土士）を利用者の指示で統合した。日本語版はひらがなだけに書き換えた（利用者が選択）。デーヴァナーガリーの例はどの言語でも同じ英語・ベトナム語・ネパール語は Claude の訳【曖昧】ベトナム語・ネパール語は母語話者の確認なし
- 表紙は利用者のデザイン（石組みの図、題字「認字」、NINJI、START）どおり。題字と START はどの言語でも同じ。アプリ名は利用者の指定で全言語「認字」（ブラウザのタブ・ホーム画面に追加したときの名前は「認字 NINJI」）
- アイコンは利用者のデザイン（石組みに「認」）。角丸の外側を紙の色で埋めて正方形にし、各サイズを作った
- 全画面の見た目を表紙に合わせた（紙の白・墨の四角・角なし・字間を空けた明朝）
- アプリ説明は流す演出をやめ、文章と挿絵をまとめた1枚のページを利用者がスクロールして読む形にした（流す方式は利用者の端末で2度とも途中で消えたため、利用者の指示）。下の「つぎ」でいつでもホームへ進める
- 表示言語はどの画面でも右上から切り替えられる。練習の画面上部の段階切り替えは、モード選択の画面に置き換えた
- テスト96件・型の確認が通り、全画面を幅390pxで目視確認した

**次にやること**

- 公開後、アプリを開き直して、説明のページ・挿絵・アイコンを確認してもらう（rahiseko-alt/Kanji-ninsiki#32・#34 で main に取り込み済み。新しい版は、アプリを完全に閉じて開き直すのを2回繰り返すと出る。アイコンはホーム画面に追加し直さないと替わらないことがある）

**未解決の問題**

- ベトナム語・ネパール語の説明文は母語話者の確認が要る【曖昧】
- 明朝体は線の細い部分が小さい画面で見えにくい可能性がある。試用で確かめる【曖昧】

## 2026-09-25 利用者への説明を普通の大人向けの文体にした／アプリの位置づけを確認した

**決めたこと**

- 利用者の指示「子供みたいな書き方をするな」を受け、flow-map.md の「説明の書き方」から、専門用語を日常語に置き換える規則と置き換え表を削除した。3ブロック（結論・理由・次）は維持
- アプリの位置づけは「漢字を覚えるための基礎となる力（漢字を字として見分ける力）を訓練する」で利用者と合意。「これで覚えられる」とは書かない
- 研究調査の結論: 非漢字圏学習者が漢字を字として捉えにくい理由（字形の複雑さ、部品に分解できない、似た字の取り違え、音に頼る読み方）は論文で裏付けがある。形の見分け練習だけで漢字を覚えやすくなるかは未検証

**次にやること**

- 研究の出典は docs/research/kanji-recognition-evidence.md に保存した。README にアプリの位置づけを書き足すかは利用者の判断待ち

**未解決の問題**

- 明朝体は線の細い部分が小さい画面で見えにくい可能性がある。試用で確かめる【曖昧】
